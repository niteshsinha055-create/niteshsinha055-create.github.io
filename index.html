TESTING METHODOLOGY / HOW I WORK

Careful testing, clear communication.

I test the way a real user behaves and the way an attacker would. That means validating happy paths, boundary anomalies, expired bearer sessions, and fractured transport connections, then structuring every defect with reproduction steps, network diagnostics, and zero ambiguity.

In collaborative Agile squads, I anchor the QA lifecycle from initial PRD specs through continuous smoke suites. Over the past year, I have transitioned core repetitive regression overhead into deterministic automated suites: Playwright scripts in Java and JavaScript for browser applications, and Appium for Android and iOS execution, integrated directly into GitHub Actions CI workflows.
