About

Careful testing, clear communication

I test the way a real user behaves and the way an attacker would. That means checking happy paths, odd inputs, expired sessions and broken connections, then writing up each problem with exact steps, severity and evidence.

I work in Agile teams, plan test coverage from requirements, run regression and smoke suites before each release, and mentor junior testers. Over the past year I have moved a growing share of regression into automation: Playwright scripts in Java and JavaScript for web, and Appium for Android and iOS, with API and UI checks running in GitHub Actions.
